\# Disaster Response Classifier



Multi-label classifier that categorizes disaster-related messages

so they can be routed to the right relief agency.



\## Project structure

\- `data/` - raw dataset (see `data/README.md`)

\- `notebooks/` - exploration and experiments

\- `src/` - reusable code

\- `models/` - trained models (not tracked)



\## Setup

&#x20;   python -m venv .venv

&#x20;   .venv\\Scripts\\activate

&#x20;   pip install -r requirements.txt



\## Contributing

1\. `git pull` on `main`

2\. Create a branch: `git switch -c feature/<name>-<task>`

3\. Commit small, open a Pull Request, get one review, then merge



Never push directly to `main`.
